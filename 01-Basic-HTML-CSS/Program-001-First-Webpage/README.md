# Program #001 – Create Your First HTML Webpage 🌐

Welcome to **HTML & CSS Practice Program #001** by **CodeWithPankaj**!

In this beginner-friendly project, you will learn how to create your first webpage using HTML5 and CSS3.

You will understand the basic HTML structure, add headings and paragraphs, create a skills list, add a hyperlink and style the webpage using CSS.

## 🎯 Learning Objectives

After completing this program, you will learn:

- What HTML is and how it works.
- Basic HTML document structure.
- How to create headings and paragraphs.
- How to create unordered lists.
- How to add hyperlinks.
- How to connect an external CSS file.
- How to apply basic CSS styling.
- How to create a button hover effect.

## 🚀 How to Run This Project

1. Download or clone the repository.
2. Open the `Program-001-First-Webpage` folder.
3. Open the folder in Visual Studio Code.
4. Open the `index.html` file.
5. Right-click and select Open with Live Server, or open the file directly in your browser.
6. Your first webpage will appear in the browser.

## 📖 HTML Concepts Explained

| HTML Tag          | Description                      |
| ----------------- | -------------------------------- |
| `<!DOCTYPE html>` | Declares an HTML5 document       |
| `<html>`          | Defines the HTML document        |
| `<head>`          | Contains webpage information     |
| `<meta>`          | Provides metadata                |
| `<title>`         | Sets the browser tab title       |
| `<body>`          | Contains visible webpage content |
| `<div>`           | Groups webpage elements          |
| `<h1>`            | Creates the main heading         |
| `<h2>`            | Creates a second-level heading   |
| `<p>`             | Creates a paragraph              |
| `<ul>`            | Creates an unordered list        |
| `<li>`            | Creates a list item              |
| `<a>`             | Creates a hyperlink              |

## 🎨 CSS Properties Explained

| CSS Property       | Description                    |
| ------------------ | ------------------------------ |
| `font-family`      | Changes the text font          |
| `background-color` | Changes the background colour  |
| `margin`           | Adds outside spacing           |
| `padding`          | Adds inside spacing            |
| `width`            | Sets the element width         |
| `max-width`        | Sets the maximum width         |
| `border-radius`    | Creates rounded corners        |
| `text-align`       | Aligns the text                |
| `color`            | Changes text colour            |
| `font-size`        | Changes text size              |
| `display`          | Controls element display       |
| `text-decoration`  | Controls text decoration       |
| `:hover`           | Applies styling on mouse hover |
