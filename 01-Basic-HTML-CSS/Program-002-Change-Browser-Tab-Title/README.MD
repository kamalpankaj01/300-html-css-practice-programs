# HTML & CSS Practice Program #2: Change the Browser Tab Title

Welcome to my second HTML & CSS practice program! 🚀

In this program, I learned how to change the browser tab title using the HTML `<title>` tag.

## 📌 About This Program

The HTML `<title>` tag defines the title of a webpage. This title appears in the browser tab and helps users identify the webpage.

## 💻 Technologies Used

- HTML5
- Visual Studio Code
- Google Chrome

## 📂 Project Structure

```text
HTML-CSS-Practice/
│
├── index.html
└── README.md
```

## 📝 HTML Code

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />

    <title>My First Website</title>
  </head>

  <body>
    <h1>Welcome to My Website!</h1>

    <p>This is my second HTML practice program.</p>
  </body>
</html>
```

## 🎯 What I Learned

1. Understanding the HTML `<title>` tag.
2. Using the `<head>` section.
3. Understanding UTF-8 character encoding.
4. Using the viewport meta tag.
5. Changing the browser tab title.
6. Understanding the difference between `<title>` and `<h1>`.

## 🖥️ Expected Output

**Browser Tab Title:**
My First Website

**Webpage Heading:**
Welcome to My Website!

**Paragraph:**

## ▶️ How to Run This Program

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open the `index.html` file.
4. Right-click and select Open with Live Server, or open the file directly in your browser.
5. Check the browser tab to see the custom title.
