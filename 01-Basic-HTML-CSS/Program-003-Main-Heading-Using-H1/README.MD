## 🎯 Learning Objectives

In this practice program, I learned:

- How to use the HTML `<h1>` tag.
- How to create a main heading on a webpage.
- How to apply CSS to an H1 heading.

- How to change font size using CSS.

- How to align text in the center.
- Difference between HTML structure and CSS styling.

## 💻 Complete Source Code

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />

    <title>HTML H1 Tag Practice</title>

    <style>
      body {
        font-family: Arial, sans-serif;
        background-color: #f2f6ff;
        text-align: center;
        padding: 50px;
      }

      h1 {
        color: #ff6600;
        font-size: 36px;
        margin-bottom: 15px;
      }

      p {
        color: #444444;
        font-size: 18px;
      }
    </style>
  </head>

  <body>
    <h1>Welcome to CodeWithPankaj</h1>

    <p>I am learning HTML and CSS. This is my third practice program.</p>
  </body>
</html>
```

## 🖥️ Expected Output

The webpage displays:

- A light blue background.
- An orange main heading: **Welcome to CodeWithPankaj**.
- A paragraph below the heading.
- Center-aligned text.
