# HTML & CSS Practice Program #004 – Display All Six HTML Heading Levels

This is my **fourth HTML and CSS practice program** from the CodeWithPankaj learning series.

In this program, I learned how to display all six HTML heading levels using `<h1>` to `<h6>` and style them using CSS.

## 📌 Project Information

- **Program Number:** 004
- **Project Name:** Display All Six HTML Heading Levels
- **Technology:** HTML5 and CSS3
- **Level:** Beginner
- **File Name:** `index.html`

## 🎯 Learning Objectives

In this practice program, I learned:

- How to use HTML heading tags.
- Difference between H1, H2, H3, H4, H5, and H6.
- How to display all six heading levels.
- How to style headings using CSS.
- How to change heading colors.
- How to change font sizes.
- How to set a webpage background color.
- How to organize webpage content using heading levels.

## 💻 Complete Source Code

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />

    <title>HTML Six Heading Levels Practice</title>

    <style>
      body {
        font-family: Arial, sans-serif;
        background-color: #f2f6ff;
        padding: 30px;
      }

      h1 {
        color: #ff6600;
        font-size: 36px;
      }

      h2 {
        color: #008000;
        font-size: 30px;
      }

      h3 {
        color: #0066cc;
        font-size: 26px;
      }

      h4 {
        color: #9933cc;
        font-size: 22px;
      }

      h5 {
        color: #cc6600;
        font-size: 20px;
      }

      h6 {
        color: #444444;
        font-size: 18px;
      }
    </style>
  </head>

  <body>
    <h1>This is Heading 1</h1>

    <h2>This is Heading 2</h2>

    <h3>This is Heading 3</h3>

    <h4>This is Heading 4</h4>

    <h5>This is Heading 5</h5>

    <h6>This is Heading 6</h6>
  </body>
</html>
```

## 🖥️ Expected Output

The webpage displays:

- H1 heading in orange.
- H2 heading in green.
- H3 heading in blue.
- H4 heading in purple.
- H5 heading in dark orange.
- H6 heading in dark grey.
- Light blue webpage background.

## 📚 HTML Heading Reference

| HTML Tag | Heading Level         |
| -------- | --------------------- |
| `<h1>`   | Highest-level heading |
| `<h2>`   | Second-level heading  |
| `<h3>`   | Third-level heading   |
| `<h4>`   | Fourth-level heading  |
| `<h5>`   | Fifth-level heading   |
| `<h6>`   | Lowest-level heading  |
