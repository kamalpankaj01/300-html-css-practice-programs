# 🟢 Basic HTML & CSS – Beginner Level (Programs 001–100)

Welcome to the **Basic HTML & CSS** section of the 300 HTML & CSS Practice Programs series by **CodeWithPankaj**.

This section is designed for beginners who want to learn web development from scratch. You don't need any previous coding experience. We will start with basic HTML concepts and gradually learn CSS through practical coding exercises.

## 🎯 Learning Objectives

After completing these 100 programs, you will be able to:

- Understand HTML5 document structure.
- Work with HTML elements and attributes.
- Create headings, paragraphs and formatted text.
- Add images, hyperlinks and lists.
- Build HTML tables and forms.
- Understand semantic HTML elements.
- Learn CSS syntax and selectors.
- Apply colours, backgrounds and fonts.
- Work with margins, padding, borders and shadows.
- Style buttons, links and webpage elements.
- Build simple and attractive webpages.

## 🛠️ Technologies Used

| Technology | Purpose |

| HTML5 | Create webpage structure |

## 🚀 How to Practice

1. Choose a practice program.
2. Read its instructions and learning objectives.
3. Open the program folder in Visual Studio Code.
4. Type the code yourself.
5. Run the HTML file in your browser.
6. Understand every HTML element and CSS property.
7. Complete the mini challenge.
8. Try creating your own version.
