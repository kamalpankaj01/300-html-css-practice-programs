# 300 HTML & CSS Practice Programs 🚀

Welcome to **300 HTML & CSS Practice Programs** by **CodeWithPankaj**!

This repository is designed for beginners who want to learn HTML and CSS through practical coding exercises.

Instead of only learning theory, you will build 300 practical programs step by step, starting from basic HTML concepts and moving towards advanced webpage designs and layouts.

Whether you are a student, beginner, or aspiring web developer, this repository will help you improve your coding skills through hands-on practice.

---

## 🎯 What You'll Learn

By completing these 300 practical programs, you will learn:

- HTML5 fundamentals
- CSS3 fundamentals
- HTML elements and attributes
- Headings, paragraphs and text formatting
- Images, links and lists
- Tables and forms
- CSS selectors and properties
- Colours, backgrounds and typography
- CSS box model
- Flexbox and CSS Grid
- Responsive web design
- CSS animations and transitions
- Modern webpage layouts
- Practical website components

---

## 📚 Learning Roadmap

The repository is divided into three learning levels.

### 🟢 Level 1: Basic HTML & CSS (Programs 001–100)

Learn the fundamentals of HTML and CSS and build your first webpages.

Topics include:
- HTML document structure
- Headings and paragraphs
- Text formatting
- Links and images
- Lists and tables
- Basic CSS styling
- Colours and backgrounds
- Borders and spacing

### 🟡 Level 2: Intermediate HTML & CSS (Programs 101–200)

Improve your skills by creating practical webpage components and layouts.

Topics include:
- HTML forms
- CSS selectors
- Box model
- Display and positioning
- Flexbox
- CSS Grid
- Navigation menus
- Cards and buttons
- Responsive layouts

### 🔴 Level 3: Advanced HTML & CSS (Programs 201–300)

Create modern webpage designs and advanced user interface components.

Topics include:
- Advanced CSS layouts
- Responsive website designs
- CSS transitions
- CSS animations
- Advanced Flexbox and Grid
- Landing pages
- Portfolio layouts
- Website sections
- Modern UI components

## 🚀 How to Use This Repository

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Select any practice program.
4. Open its `index.html` file.
5. Run it in your browser.
6. Read the program explanation.
7. Complete the practice challenge yourself.

### Clone Repository

```bash
git clone https://github.com/kamalpankaj01/300-html-css-practice-programs.git
```

---

## 📖 Individual Program Structure

Each program will contain:

- `index.html` – HTML source code
- `style.css` – CSS source code
- `README.md` – Program explanation and instructions

Each practical exercise aims to include:

1. Program introduction
2. Learning objectives
3. Complete working source code
4. Step-by-step explanation
5. Expected browser output
6. Mini practice challenge

## 🏆 Practice and Improve Your Skills

The best way to learn programming is by writing code yourself.

My recommendation:

- Practise one program at a time.
- Type the code yourself.
- Experiment with different CSS properties.
- Try the challenges without looking at the solution.
- Build your own versions of each project.

Consistency is more important than speed!
